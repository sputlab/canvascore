# Coming Soon (an example page kit)

A page kit holds `kit.json`, `content.json` (the page and its blocks), an optional `preview.png` and the images the blocks use in `assets/` (written `kit:assets/logo.svg`).

Check it with `php canvascore-frontend/scripts/library-kit.php check docs/examples/library-kits/coming-soon-page` and make the ZIP with `… pack <folder>`.
