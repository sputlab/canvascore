# CanvasCore tutorials

Step-by-step guides with screenshots, from an empty hosting account to a published, multilingual site. They are short on purpose: the
[manuals](../manuals/README.md) have every detail. The screenshots come from the demo site (Lumen Studio) and are made by `scripts/screenshots.mjs`.

| # | Tutorial | You will |
| --- | --- | --- |
| 1 | [Install CanvasCore](01-install.md) | check your hosting, install with the wizard, Softaculous or the command line, and sign in |
| 2 | [Deploy on shared hosting](02-shared-hosting.md) | choose the PHP version, upload the files, protect the data folder, turn on HTTPS, send mail, schedule publishing |
| 3 | [Build your first site](03-first-site.md) | make pages from templates, edit blocks, set up the menu, publish |
| 4 | [Manage the site](04-manage.md) | add people with roles, keep backups, update in one click, run a blog, a popup and a second language |
| 5 | [Run a public demo](05-public-demo.md) | put a demo online that resets itself, on hosting without SSH |

Also in Italian: [tutorial in italiano](it/README.md).
